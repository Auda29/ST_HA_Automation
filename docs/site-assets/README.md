# Project website

GitHub Pages serves `docs/` from `master`. German is
`index.html`; English is `en.html`. Both use `site.css`, `language.js` and
`site.js`. Edit both HTML files when changing copy or links. No build step,
external fonts, analytics, runtime dependencies or external image requests are used.

## Sources and illustrations

- `icon.png`: unchanged copy of `custom_components/st_hass/brand/icon.png`.

The code view is an authored illustration based on the motion-light tutorial. The motion button demonstrates IF logic using JavaScript only. It neither invokes the transpiler nor connects to Home Assistant. The German website copy is intentional; the application UI and technical documentation remain English.

Initial copy and downloads were checked against repository documentation and the
published `v2.1.6` release on 2026-11-11. Keep prerelease
labels and compatibility limits aligned with future release changes.
