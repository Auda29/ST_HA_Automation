01

Bind entities

Bind inputs with %I*, outputs with %Q* and helpers with %M*. The Entity Browser supports selecting and inserting bindings.

02

Express behaviour

Use conditions, state variables and timers such as TON, TOF or TP. Pragmas control triggers, persistence and execution mode.

03

Inspect values

Syntax highlighting and autocomplete help while writing. Online mode displays current entity values in the editor.

02 / FROM PROGRAM TO AUTOMATION

Write ST.

Deployment backs up configuration and includes error handling and rollback. Review the preview and start by testing a small automation.

03 / SETUP

Your first
ST automation.

Add the HACS repository

Add the repository as a custom Integration in HACS and install ST for Home Assistant.

Restart and add

Restart Home Assistant. Add ST for Home Assistant under Settings → Devices & services.

Open ST Editor

Open the new sidebar panel and create your first program. Replace the example IDs with real entities.

Preview and test

Check the diagnostics, click Deploy and test the behavior with two Toggle helpers first.

HACS · Custom repository, type Integration

https://github.com/Auda29/ST_HA_Automation

Requirements

Home Assistant 2024.7.0 or newer and HACS for the recommended installation. No additional PLC hardware is required.

Manual installation

Alternatively, extract the release archive and copy custom_components/st_hass into your custom_components directory. Then restart and add the integration.

GOOD TO KNOW

Before you start.

Does my ST code run in a continuous loop?

The integration generates native, event-driven Home Assistant automations. It does not emulate a cyclic PLC task with real-time guarantees.

Can I connect the example switch to my home?

The demo on this page only shows the IF logic in your browser. Install the integration and replace the entity IDs in the program to use real entities.

Is the application interface bilingual too?

This project site is available in German and English. The editor interface and most technical references are in English.
